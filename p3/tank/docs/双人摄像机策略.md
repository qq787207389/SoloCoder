# 双人摄像机策略设计文档

## 概述

《钢铁战神》坦克大战支持本地双人同屏游戏。本项目采用**居中缩放策略**，保证两名玩家始终在屏幕内，同时提供最佳的视野范围。

## 设计目标

1. **双玩家可见**: 确保两名玩家坦克始终在屏幕视野内
2. **平滑过渡**: 摄像机移动平滑，避免突兀跳跃
3. **边界限制**: 摄像机不超出地图边界
4. **缩放合理**: 根据玩家距离动态调整缩放级别

## 高级摄像机策略方案

### 方案一：边界盒跟随策略

```typescript
class CameraSystem {
  private bounds: Rectangle;
  private smoothing: number = 0.1;
  private minZoom: number = 0.8;
  private maxZoom: number = 1.2;
  
  update(players: PlayerTank[]): void {
    // 1. 计算所有玩家的包围盒
    const playerBounds = this.calculatePlayerBounds(players);
    
    // 2. 计算所需缩放级别
    const requiredZoom = this.calculateRequiredZoom(playerBounds);
    
    // 3. 计算摄像机目标位置
    const targetCenter = playerBounds.center;
    
    // 4. 平滑插值移动
    this.smoothMove(targetCenter, requiredZoom);
  }
  
  private calculatePlayerBounds(players: PlayerTank[]): Rectangle {
    let minX = Infinity, maxX = -Infinity;
    let minY = Infinity, maxY = -Infinity;
    
    for (const player of players) {
      minX = Math.min(minX, player.position.x);
      maxX = Math.max(maxX, player.position.x + player.bounds.width);
      minY = Math.min(minY, player.position.y);
      maxY = Math.max(maxY, player.position.y + player.bounds.height);
    }
    
    // 添加边缘缓冲
    const padding = 64;
    return new Rectangle(
      minX - padding,
      minY - padding,
      maxX - minX + padding * 2,
      maxY - minY + padding * 2
    );
  }
  
  private calculateRequiredZoom(bounds: Rectangle): number {
    const screenRatio = this.canvas.width / this.canvas.height;
    const boundsRatio = bounds.width / bounds.height;
    
    let zoom: number;
    if (boundsRatio > screenRatio) {
      zoom = this.canvas.width / bounds.width;
    } else {
      zoom = this.canvas.height / bounds.height;
    }
    
    return Math.clamp(zoom, this.minZoom, this.maxZoom);
  }
}
```

### 方案二：分屏模式

```typescript
class SplitScreenRenderer {
  render(ctx: CanvasRenderingContext2D, players: PlayerTank[]): void {
    if (players.length === 1) {
      this.renderSinglePlayer(ctx, players[0]);
    } else if (players.length === 2) {
      // 垂直分屏
      this.renderVerticalSplit(ctx, players);
      // 或水平分屏
      // this.renderHorizontalSplit(ctx, players);
    }
  }
  
  private renderVerticalSplit(ctx: CanvasRenderingContext2D, players: PlayerTank[]): void {
    const halfWidth = ctx.canvas.width / 2;
    
    // 左屏 - 玩家1
    ctx.save();
    ctx.beginPath();
    ctx.rect(0, 0, halfWidth, ctx.canvas.height);
    ctx.clip();
    this.renderPlayerView(ctx, players[0], 0);
    ctx.restore();
    
    // 右屏 - 玩家2
    ctx.save();
    ctx.beginPath();
    ctx.rect(halfWidth, 0, halfWidth, ctx.canvas.height);
    ctx.clip();
    this.renderPlayerView(ctx, players[1], halfWidth);
    ctx.restore();
    
    // 分割线
    ctx.strokeStyle = '#ffd700';
    ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.moveTo(halfWidth, 0);
    ctx.lineTo(halfWidth, ctx.canvas.height);
    ctx.stroke();
  }
  
  private renderPlayerView(ctx: CanvasRenderingContext2D, player: PlayerTank, offsetX: number): void {
    const centerX = ctx.canvas.width / 4 + offsetX;
    const centerY = ctx.canvas.height / 2;
    
    const cameraX = player.getCenter().x - centerX;
    const cameraY = player.getCenter().y - centerY;
    
    ctx.save();
    ctx.translate(-cameraX + offsetX, -cameraY);
    // 渲染地图和游戏对象
    ctx.restore();
  }
}
```

## 摄像机效果对比

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **全局居中** | 实现简单，视野完整，无缩放变形 | 单玩家时视野较小，地图过大时看不清细节 | 小地图，经典玩法 |
| **动态缩放** | 自动适应玩家距离，视野最优 | 实现复杂，缩放可能导致变形 | 中大型地图，自由移动 |
| **垂直分屏** | 两人都有最佳视野，互不干扰 | 分割线影响体验，无法看到对方全貌 | 大地图，竞技模式 |
| **水平分屏** | 上下视野宽，适合横向地图 | 左右视野窄 | 特定地图设计 |

### 摄像机震动效果
```typescript
shake(intensity: number, duration: number): void {
  this.shakeIntensity = intensity;
  this.shakeDuration = duration;
  this.shakeTimer = 0;
}

updateShake(deltaTime: number): void {
  if (this.shakeTimer < this.shakeDuration) {
    this.shakeOffset.x = (Math.random() - 0.5) * this.shakeIntensity * 2;
    this.shakeOffset.y = (Math.random() - 0.5) * this.shakeIntensity * 2;
    this.shakeTimer += deltaTime;
  } else {
    this.shakeOffset.set(0, 0);
  }
}
```

## 总结

当前项目采用**全局居中固定缩放**策略，适合13x13的小地图坦克大战游戏。如果未来需要扩展更大地图或更灵活的摄像机，可以：

1. 实现动态缩放摄像机
2. 添加分屏模式切换
3. 实现小地图功能
4. 添加摄像机特效（震动、聚焦等）
