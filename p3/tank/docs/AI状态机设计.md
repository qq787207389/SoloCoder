# AI状态机设计文档

## 概述

《钢铁战神》坦克大战游戏的AI系统采用状态机设计模式，实现了五种不同类型的敌人AI，每种AI都有独特的行为模式和决策逻辑。

## AI类型枚举

```typescript
enum AIType {
  NORMAL = 'normal',    // 普通敌人
  CHASER = 'chaser',    // 追击型敌人
  DODGER = 'dodger',    // 闪避型敌人
  ELITE = 'elite',      // 精英敌人
  BOSS = 'boss'         // BOSS级敌人
}
```

## AI状态定义

```typescript
enum AIState {
  IDLE = 'idle',        // 待机状态
  PATROL = 'patrol',    // 巡逻状态
  CHASE = 'chase',      // 追击状态
  DODGE = 'dodge',      // 闪避状态
  ATTACK = 'attack',    // 攻击状态
  FLEE = 'flee'         // 逃跑状态
}
```

## 各类型AI行为设计

### 1. 普通AI (NORMAL)
- **行为模式**: 随机巡逻，偶尔转向
- **移动策略**: 每隔1-3秒随机改变方向
- **攻击策略**: 同一条直线上有玩家时自动射击
- **特点**: 最基础的敌人类型，适合作为前期波次敌人

### 2. 追击型AI (CHASER)
- **行为模式**: 主动追踪最近的玩家
- **移动策略**:
  - 计算与最近玩家的向量距离
  - 根据X/Y轴差值判断优先移动方向
  - 水平差值大则左右移动，垂直差值大则上下移动
- **攻击策略**: 同线必射，射击频率高于普通AI
- **特点**: 对玩家有威胁，适合中期波次

### 3. 闪避型AI (DODGER)
- **行为模式**: 保持距离，反向移动
- **移动策略**:
  - 与追击型相反，远离最近玩家
  - 玩家靠近时反向移动
  - 主动规避玩家火力
- **攻击策略**: 较低射击频率，注重生存
- **特点**: 难以击杀，适合配合其他AI出现

### 4. 精英AI (ELITE)
- **行为模式**: 混合策略，智能切换
- **移动策略**:
  - 50%概率追击玩家
  - 50%概率随机巡逻
  - 根据战场情况动态调整
- **攻击策略**: 高频率射击，预判玩家移动
- **特点**: 血量翻倍，分数更高，中后期强力敌人

### 5. BOSS AI (BOSS)
- **行为模式**: 终极BOSS，拥有特殊子弹
- **移动策略**:
  - 70%概率追击玩家
  - 30%概率随机移动
  - 移动速度较慢但稳定
- **攻击策略**: 三种特殊子弹随机发射
  - **散弹**: 向四个方向同时发射
  - **旋转弹**: 螺旋轨迹飞行
  - **追踪弹**: 自动追踪玩家位置
- **特点**: 5倍血量，高分数奖励，每5波出现

## 状态转换机制

### 状态触发条件

```
PATROL → CHASE: 玩家进入视野范围
CHASE → ATTACK: 与玩家同一直线
ATTACK → PATROL: 失去目标视野
ANY → DODGE: 受到攻击或附近有子弹
DODGE → PATROL: 危险解除
```

### 决策频率

- **方向改变**: 每1-3秒评估一次
- **射击判定**: 每帧检测
- **状态转换**: 每0.5秒评估一次

## 子弹系统

### 普通子弹
- 直线飞行
- 碰撞墙壁或坦克后消失
- 可破坏砖墙

### 散弹 (SPREAD)
- BOSS专属
- 同时向4个方向发射
- 金黄色弹道

### 旋转弹 (SPIN)
- BOSS专属
- 螺旋轨迹飞行
- 青蓝色弹道
- 难以预判

### 追踪弹 (TRACKING)
- BOSS专属
- 自动追踪最近玩家
- 紫红色弹道
- 持续修正飞行方向

## 生成系统

### 波次配置
```typescript
每波敌人数量 = 基础数量(4) + Math.floor(波次 / 2)
每5波 → BOSS波
波次 > 3 → 精英/追击/闪避型敌人概率增加
```

### 生成位置
- 地图顶部三个出生点
- 避免重叠生成
- 有1秒无敌时间

## 与玩家交互

### 视野检测
- 同一直线检测（X或Y轴对齐）
- 无视墙壁遮挡（简化处理）
- 检测范围全屏

### 难度递增
- 波次越高，高级AI概率越大
- BOSS波次前有预警时间
- 敌人移动速度随波次小幅提升

## 性能优化

### 空间索引
- 使用Grid空间划分
- 只检测相邻格子的碰撞
- 减少O(n²)复杂度

### 计算频率控制
- 距离计算每5帧一次
- 路径决策每10帧一次
- 子弹追踪每帧更新
