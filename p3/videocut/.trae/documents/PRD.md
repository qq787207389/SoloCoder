## 1. 产品概述

纯前端视频剪辑预览工具，基于 WebCodecs、Canvas 和 Web Audio API 实现浏览器端媒体处理，无需后端服务。支持视频上传、多轨道时间轴编辑、片段裁剪拼接、文字叠加，提供实时预览功能。

- **核心价值**：零依赖的浏览器端视频编辑体验，无需上传服务器，保护用户隐私
- **目标用户**：需要快速剪辑视频片段的内容创作者、教育工作者、普通用户

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 使用所有编辑功能，保存/加载项目文件 |

### 2.2 功能模块
1. **编辑器主页**：视频上传区、预览画布、时间轴、属性面板
2. **媒体处理模块**：视频解码、音频分析、缩略图生成、波形图绘制
3. **时间轴模块**：多轨道编辑、片段拖拽、入点出点裁剪、缩放、播放头跟随
4. **实时渲染模块**：Canvas 帧合成、WebCodecs 解码、Web Audio 混音
5. **文字叠加模块**：文本创建、样式设置、时间区间控制
6. **项目管理模块**：JSON 项目保存/加载、WebM 导出（可选）

### 2.3 功能详情
| 模块名称 | 子功能 | 功能描述 |
|----------|--------|----------|
| 视频上传 | 文件选择 | 支持拖拽和点击上传 MP4/WebM 视频 |
| | 媒体分析 | 自动抽取视频缩略图、音频波形图 |
| 时间轴编辑 | 多轨道 | 支持多个视频轨道和音频轨道 |
| | 片段操作 | 拖拽移动、缩放调整时长、删除片段 |
| | 裁剪控制 | 入点出点手柄精确裁剪 |
| | 时间缩放 | 滚轮缩放时间轴精度 |
| 实时预览 | Canvas 渲染 | 实时合成视频帧、文字图层 |
| | 播放控制 | 播放/暂停、进度跳转、播放头跟随 |
| | 音频混合 | 多片段音频混合、音量调节 |
| 文字叠加 | 文本编辑 | 支持自定义文本内容 |
| | 样式设置 | 字体、大小、颜色、位置 |
| | 时间控制 | 设置出现和消失的时间区间 |
| 项目管理 | 保存项目 | 导出 JSON 项目配置文件 |
| | 加载项目 | 导入 JSON 恢复编辑状态 |
| | 导出视频 | 使用 MediaRecorder 录制 Canvas 输出 WebM |

## 3. 核心流程

用户上传视频 → 系统分析媒体生成缩略图和波形 → 用户在时间轴排布片段、设置裁剪 → 添加文字叠加并调整样式和时间 → 实时预览编辑效果 → 保存项目或导出视频

```mermaid
    C --> D["添加文字"]
    D --> E["实时预览"]
    E --> F["保存/导出"]
    C --> E
    D --> E
```

## 4. 界面设计

### 4.1 设计风格
- **主色调**：深色主题 (#0f172a)，配合科技蓝 (#3b82f6) 作为强调色
- **按钮风格**：圆角 4px，悬停有微妙的亮度变化和阴影
- **字体**：Inter 无衬线字体，等宽字体用于时间码显示
- **布局**：三栏布局 - 左侧工具面板、中间预览画布、底部时间轴
- **视觉风格**：专业剪辑软件风格，深色低对比度，减少眼睛疲劳

### 4.2 页面设计
| 区域 | 模块 | UI 元素 |
|------|------|---------|
| 顶部 | 工具栏 | 导入按钮、保存按钮、导出按钮、播放控制 |
| 左侧 | 媒体库 | 已上传视频列表、拖拽添加到轨道 |
| 中间 | 预览区 | Canvas 画布、播放控制条、时间码显示 |
| 底部 | 时间轴 | 多轨道容器、轨道头、片段块、缩放控制、播放头 |
| 右侧 | 属性面板 | 选中片段属性、文字样式编辑器 |

### 4.3 响应式设计
- 桌面端为主要目标，保证 1920×1080 分辨率下的最佳体验
- 时间轴区域支持横向滚动以适配长视频
- 面板可折叠以增加预览区域空间
