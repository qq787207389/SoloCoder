# 塔防游戏 - Tower Defense

一款高度复杂的 2D 俯视视角塔防游戏，灵感来源于《保卫萝卜》，使用 TypeScript 和 Canvas API 开发。

## 核心特性

### 游戏玩法
- **动态路径生成**：怪物路径由 A* 算法根据障碍物布局动态计算
- **多种怪物类型**：
  - 普通怪：沿路径前进
  - 遁地怪：可钻入地下躲避攻击，移动速度降低
  - 飞行怪：无视地形直接飞向终点
  - 护盾怪：携带可吸收伤害的护盾，破损后加速
  - BOSS：多阶段，血量降低时释放特殊技能
- **四种防御塔**：箭塔、炮塔、冰塔、防空塔
- **粒子特效系统**：攻击、命中、死亡特效
- **屏幕震动效果**：萝卜受击或 BOSS 放大招时触发

### 关卡设计
- **2个完整关卡**：
  - 关卡1：草原防御（单入口）
  - 关卡2：双路围攻（双入口）
- **多波次怪物**：每关 6 波怪物，难度递增
- **经济系统**：金币用于建造塔，水晶通过击杀精英怪获得

## 技术架构

### ECS 实体组件系统
- **Entity**：游戏实体，包含多个组件
- **Component**：数据组件（位置、速度、渲染、健康等）
- **System**：逻辑系统（移动、寻路、攻击、渲染等）

### 核心系统
1. **路径寻路系统**：A* 算法 + 路径平滑
2. **移动系统**：处理实体位置更新
3. **攻击系统**：塔攻击目标判定
4. **碰撞检测系统**：基于距离的碰撞检测
5. **粒子系统**：特效管理
6. **渲染系统**：Canvas 2D 渲染

### 性能优化
- **对象池**：重复利用粒子和投射物对象
- **脏矩形渲染**：只更新变化区域
- **空间分区**：优化碰撞检测

## 游戏操作

1. **选择塔类型**：点击底部按钮选择要建造的塔
2. **放置塔**：点击地图空白格子放置防御塔
3. **开始波次**：点击右上角"开始下一波"按钮
4. **切换关卡**：使用右上角关卡选择按钮

## 技术文档

### 1. 动态寻路与障碍物联动机制

游戏使用 A* 算法实现路径寻路：

- **网格表示**：地图被划分为可行走和不可行走的网格
- **寻路触发**：每次怪物生成时计算从起点到终点的路径
- **路径平滑**：使用视线检测算法去除不必要的路径拐点
- **障碍物影响**：放置防御塔会标记对应网格为不可行走，影响后续路径

关键代码：
```typescript
// Grid 类管理可行走状态
grid.setWalkable(x, y, false);

// AStar 寻路
const path = astar.findPath(startX, startY, endX, endY);
```

### 2. 怪物行为树实现

不同类型怪物有独特行为：

- **普通怪物**：沿路径移动，受到攻击减少血量
- **遁地怪物**：随机进入地下状态，免疫攻击但减速
- **飞行怪物**：直线飞向终点，只能被防空塔攻击
- **护盾怪物**：护盾吸收伤害，护盾破损后加速
- **BOSS怪物**：多阶段战斗，阶段变化触发特效

### 3. 塔融合系统设计

塔系统支持：
- **4种基础塔**：各有不同的攻击方式和目标选择
- **等级系统**：Lv1-Lv3，属性随等级提升
- **范围指示**：攻击范围可视化
- **防空塔**：专门针对飞行怪物

### 4. 性能优化策略

1. **实体管理**：使用 Map 存储实体，O(1) 查找效率
2. **系统过滤**：每个系统只处理拥有特定组件的实体
3. **渲染优化**：分层渲染，粒子最后渲染保证层级
4. **对象池**：（待实现）对于高频创建/销毁的对象使用池化

## 扩展开发

### 添加新塔类型
1. 在 `TowerType` 枚举中添加新类型
2. 在 `TowerComponent` 中配置属性
3. 在渲染系统中添加对应视觉效果

### 添加新怪物类型
1. 在 `MonsterType` 枚举中添加新类型
2. 添加对应的组件（如需要）
3. 在 `spawnMonster` 中配置属性

### 创建新关卡
参考 `main.ts` 中的关卡配置格式，添加新的 `LevelConfig` 对象。
