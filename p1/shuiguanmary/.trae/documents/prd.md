## 1. 产品概述

《水管玛丽》是一款经典像素风格的单屏动作游戏，玩家操控玛丽在地下管道室中与不断涌出的敌人战斗。核心玩法是"顶板翻敌→攀爬追击→踢飞连锁"的操作链，配合惯性移动手感，形成快节奏、高技巧性的战斗体验。游戏没有终点，目标是尽可能撑过更多波次刷新高分。

- 目标用户：喜欢经典平台动作游戏、追求操作手感的玩家
- 核心价值：将马里奥系列的顶板机制升华为完整的战斗系统，惯性移动与精准判定的结合带来独特的操作深度

## 2. 核心功能

### 2.2 功能模块

1. **游戏主场景**：地下管道室场景渲染、多层平台布局、砖墙与水管阀门背景
2. **角色控制系统**：惯性移动、跳跃、空中微调、顶板攻击、踢飞敌人
3. **敌人系统**：乌龟/螃蟹/飞虫三种敌人AI、顶翻挣扎机制、恢复计时
4. **战斗系统**：顶板判定、踢飞连锁、火球躲避
5. **波次系统**：渐进式出怪、难度递增、波次间歇
6. **UI系统**：分数显示、波次显示、游戏开始/结束界面

## 3. 核心流程

玩家进入游戏后，玛丽出现在管道室底部。敌人从顶部两根绿色水管涌出，玩家通过顶板攻击将平台上的敌人震翻，然后攀爬到敌人所在平台补踢。踢飞的敌人沿直线滑出，碰到其他敌人可连锁消灭。未被补踢的敌人会在数秒后翻回。火球从水管间歇喷出，沿平台滚动反弹，需要躲避。每清完一波敌人短暂停歇，下一波立刻开始，难度逐渐递增。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深棕色砖墙底色 + 亮绿色水管 + 天蓝色角色服装
- 辅助色：红色（敌人/危险）、橙色（火球）、金色（分数）
- 像素质感：8-bit/16-bit混合风格，角色和物体使用像素手绘sprite
- 布局：固定单屏，16:9或4:3比例，无滚动
- 字体：像素风点阵字体（如 Press Start 2P）
- UI风格：复古街机风格，顶部HUD信息栏

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 游戏主画面 | 场景背景 | 砖墙纹理、水管阀门装饰、暗色调地下氛围 |
| 游戏主画面 | 平台 | 石砖平台、顶板时有视觉反馈（抖动/碎片） |
| 游戏主画面 | 绿色水管 | 顶部左右各一根，出怪时有动画 |
| 游戏主画面 | 玛丽 | 像素风角色、行走/跳跃/顶板/踢飞动画 |
| 游戏主画面 | 敌人 | 乌龟（绿壳）、螃蟹（红壳）、飞虫（紫色翅膀） |
| 游戏主画面 | HUD | 顶部居中显示"SCORE: xxx  WAVE: xx" |
| 标题画面 | 开始界面 | 大标题"水管玛丽"、闪烁的"按空格开始"文字 |

### 4.3 响应式

- 桌面优先设计，固定游戏画布尺寸（800x600或类似）
- 画布居中显示，背景填充黑色
- 键盘操控为主（方向键+空格/Z/X）

### 4.4 操作说明

| 按键 | 功能 |
|-----|------|
| ← → | 左右移动（有惯性） |
| ↑ / 空格 | 跳跃 |
| 走近翻倒敌人 | 自动踢飞 |
