# 团队协作看板

一个功能完整的团队协作看板应用，使用 React 18 + TypeScript + Vite + Tailwind CSS + dnd-kit + Zustand 构建。

## 功能特性

### 📋 看板与列表管理
- 支持创建多个看板（如「开发工作」、「个人计划」）
- 每个看板可包含多个列表（如「待处理」、「进行中」、「已完成」）
- 列表可横向排列，支持添加、重命名、删除
- 支持看板切换和管理

### 🎴 任务卡片管理
- 每张卡片包含标题、描述、标签、截止日期、优先级
- 描述支持 Markdown 简要渲染（**粗体**、*斜体*、`代码`）
- 任务逾期时卡片显示红色边框警告
- 支持按截止日期或优先级排序卡片
- 点击卡片可查看和编辑详情
- 拖拽卡片可在列表内排序或跨列表移动

### 🔍 搜索与筛选
- 顶部搜索框支持对卡片标题和描述进行模糊搜索
- 搜索结果实时高亮匹配内容
- 可按标签快速筛选卡片
- 可按优先级（高/中/低）筛选卡片

### 💾 数据持久化
- 使用 localStorage 自动保存所有看板数据
- 支持导出为 JSON 文件进行备份
- 支持从 JSON 文件恢复数据
- 首次访问时加载示例数据

### ✨ 交互体验
- 拖拽时卡片有半透明跟随和占位符效果
- 添加/编辑卡片使用模态框，支持 ESC 键关闭
- 响应式设计，适配各种屏幕尺寸
- 流畅的动画和过渡效果

## 技术栈

- **React 18** - 前端框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **Tailwind CSS** - 样式框架
- **dnd-kit** - 拖拽库
- **Zustand** - 状态管理
- **zustand-persist** - 状态持久化

## 使用说明

### 创建看板
1. 点击顶部「+ 新建看板」按钮
2. 输入看板名称并确认

### 创建列表
1. 在看板页面右侧点击「+ 添加列表」按钮
2. 输入列表名称并确认

### 创建卡片
1. 点击列表底部的「+ 添加卡片」按钮
2. 在弹出的模态框中填写卡片信息
3. 点击「创建卡片」完成

### 编辑卡片
1. 点击任意卡片打开编辑模态框
2. 修改卡片信息
3. 点击「保存修改」

### 拖拽排序
- 在同一列表内拖拽可调整卡片顺序
- 拖拽到不同列表可移动卡片

### 搜索筛选
- 使用顶部搜索框输入关键词搜索
- 点击标签按钮按标签筛选
- 使用下拉菜单按优先级或排序方式筛选

### 数据管理
- 点击「导出数据」按钮将当前数据保存为 JSON 文件
- 点击「导入数据」按钮选择 JSON 文件恢复数据
