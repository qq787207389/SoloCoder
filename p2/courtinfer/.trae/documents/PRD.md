## 1. 产品概述
法庭辩论策略游戏，玩家扮演辩护律师，通过调查取证、庭审质证和辩论为委托人争取无罪判决。
- 核心玩法：案件调查→证据收集→庭审异议→陪审团裁决
- 目标用户：喜欢推理、策略类文字冒险游戏的玩家
- 产品价值：提供沉浸式法庭辩论体验，考验逻辑推理和策略思维

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 |
|------|------|
| 辩护律师 | 玩家扮演的角色，负责调查取证和庭审辩论 |

### 2.2 功能模块
1. **主菜单**：开始游戏、案件选择、设置
2. **案件调查阶段**：行动点系统、地点探索、证据收集
3. **庭审阶段**：证人盘问、异议系统、陪审团倾向
4. **证据簿**：证据卡片展示、证据详情查看
5. **裁决界面**：陪审团裁决、结局展示

## 3. 核心流程
玩家从主菜单开始新游戏，系统随机生成案件。进入调查阶段，玩家使用行动点访问不同地点收集证据。调查结束后进入庭审，控方传唤证人作证，玩家通过阅读证词找出矛盾并用证据提出异议。成功异议提升陪审团倾向，失败降低法官信任。最终根据陪审团倾向和证据说服力给出裁决，展示案件真相和结局。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深色调为主，体现法庭庄重氛围
  - 背景：深蓝灰色 #1a1f2e
  - 强调色：金黄色 #d4af37（律师徽章）、暗红色 #8b0000（警示）
  - 文字：浅灰色 #e0e0e0
- **按钮风格**：矩形圆角，深色背景配金色边框
- **字体**：
  - 标题：宋体/衬线字体，体现正式感
  - 正文：微软雅黑，保证可读性
- **布局风格**：卡片式布局，分层显示信息
- **氛围**：使用 Canvas 绘制场景，配合光影效果增强沉浸感

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 主菜单 | 游戏标题 | 居中大标题，金色边框，打字机效果 |
| 调查地图 | 地点卡片 | 网格布局，悬停放大效果 |
| 地点调查 | 场景画布 | 全屏 Canvas，交互热点提示 |
| 证据簿 | 证据卡片 | 网格布局，翻页动画，悬停展示详情 |
| 庭审界面 | 对话区域 | 底部对话气泡，打字机效果 |
| 庭审界面 | 陪审团倾向 | 进度条，颜色渐变（红→绿） |
| 裁决界面 | 判决结果 | 全屏弹窗，动画展示 |

### 4.3 响应式设计
- 桌面优先设计
- 适配 1920x1080 及以上分辨率
- 最小支持 1280x720

### 4.4 Canvas 场景指导
- 调查场景：使用半透明叠加层营造光影效果
- 法庭场景：聚光灯效果，阴影层次
- 动画：平滑过渡，粒子效果增强氛围
