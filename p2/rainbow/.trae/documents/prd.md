## 1. 产品概述

《彩虹岛》是一款基于 Canvas 2D 的像素风横版跳跃游戏，玩家操控可爱小人通过绘制彩虹来战斗和探索。彩虹既是武器也是平台，敌人触碰彩虹会被弹飞消灭，玩家可踩着自绘彩虹攀爬到高处。关卡从海面垂直向上延伸至天空，充满云朵、泡泡和漂浮岛屿，Boss 战需要巧妙利用彩虹搭建掩体和发起攻击。

- 目标用户：喜欢休闲像素风动作游戏的玩家
- 核心价值：独特的"画彩虹"机制带来自由度极高的空间探索和战斗体验

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 |
|------|------|
| 玩家 | 操控小人进行跳跃、画彩虹、消灭敌人、收集道具 |

### 2.2 功能模块
1. **游戏主界面**: 标题画面、开始游戏、操作说明
2. **游戏关卡**: 垂直延伸的彩虹世界，从海面到天空
3. **Boss 战**: 特殊关卡，需策略性使用彩虹

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主界面 | 标题动画 | 像素风格标题，彩虹渐变背景动画 |
| 游戏主界面 | 操作说明 | 显示键盘操作提示 |
| 游戏关卡 | 玩家控制 | 左右移动、跳跃、画彩虹攻击 |
| 游戏关卡 | 彩虹系统 | 按住攻击键画彩虹，松开后逐渐消失；彩虹可踩踏、可困敌 |
| 游戏关卡 | 平台系统 | 云朵平台、移动泡泡、漂浮岛屿 |
| 游戏关卡 | 敌人系统 | 甲虫(地面)、水母(空中)、飞龙(弹幕) |
| 游戏关卡 | 道具系统 | 普通道具和稀有高空道具 |
| Boss 战 | Boss AI | Boss 发射弹幕，需用彩虹搭建掩体躲避并反击 |
| 游戏关卡 | 相机系统 | 垂直跟随玩家，平滑滚动 |

## 3. 核心流程

玩家进入游戏 → 选择开始 → 从海面底部出发 → 向上跳跃探索 → 绘制彩虹作为平台和武器 → 消灭沿途敌人 → 收集道具 → 到达关卡顶端 → 进入 Boss 战 → 利用彩虹策略击败 Boss → 进入下一关

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：天蓝色(#87CEEB)背景 + 七彩彩虹渐变(#FF0000→#FF7F00→#FFFF00→#00FF00→#0000FF→#4B0082→#9400D3)
- 像素风格：所有图形采用像素化渲染，8x8 或 16x16 像素单元
- 圆润可爱的角色设计，明亮的色彩搭配
- 像素字体用于所有文字显示
- 横版布局，相机垂直滚动

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 游戏主界面 | 标题动画 | 像素风大标题，彩虹色渐变，云朵飘动背景 |
| 游戏主界面 | 操作说明 | 像素风文字框，键盘图标提示 |
| 游戏关卡 | HUD | 左上角生命值(爱心)、右上角分数、道具栏 |
| 游戏关卡 | 场景 | 渐变天空背景、云朵、海面、平台 |
| 游戏关卡 | 玩家 | 像素小人，带走路/跳跃/画彩虹动画 |
| 游戏关卡 | 彩虹 | 七彩渐变弧线，带闪光粒子效果 |
| 游戏关卡 | 敌人 | 像素甲虫/水母/飞龙，带简单动画 |
| Boss 战 | Boss | 大型像素 Boss，带攻击动画 |

### 4.3 响应式
- 桌面优先，Canvas 自适应窗口大小
- 保持 16:9 宽高比，居中显示
- 键盘操控为主

### 4.4 键盘操控
| 按键 | 功能 |
|------|------|
| 方向键左/右 / A/D | 左右移动 |
| 方向键上 / W / 空格 | 跳跃 |
| J / Z | 画彩虹(按住持续画，松开逐渐消失) |
| K / X | 特殊技能(踩塌彩虹连锁攻击) |
